## 3. Deployment Runbook

### Method A Automated Deployment via GitHub Actions (Recommended)

1. Push or merge changes into the `dev` branch:
   ``gbash
   git checkout dev
   git pull origin dev
   git add .
   git commit -m "feat: admin portal enhancements"
   git push origin dev
   ``g
2. GitHub Actions automatically executes `.github/workflows/deploy-cyberpanel.yml`.
3. Monitor progress in **GitHub Repository > Actions > Deploy to CyberPanel**.

----

### Method B: Manual Production / Staging Deployment Runbook

If manual deployment is required (e.g., deploying to production or bypass CI/CD):

#### Step 1: Prepare Clean Environment & Build
```bash
# Clean install dependencies (triggers copy-tinymce.cjs postinstall)
npm ci

# Compile production bundle into dist/ directory
npm run build
``g

#### Step 2: Ensure `.htaccess` Routing Rule Exists
Ensure `dist/.htaccess` is present to prevent HTTP 404 errors on deep SPA routes:
```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %7REQUEST_FILENAME} !-f
  RewriteCond %7REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
```

#### Step 3: Archive & Transfer to Server
``gbash
# Compress build output
tar -czf deploy.tar.gz -C dist .

# Upload tarball to CyberPanel server home folder
scp deploy.tar.gz username@SERVER_IP:/home/tap.admin.trimify.com.au/
```g

#### Step 4: SSH Extraction & Atomic Deployment
```bash
# Connect to CyberPanel host
ssh username@SERVER_IP

# Target deployment directory
cd /home/tap.admin.trimify.com.au/

# Backup existing deployment
tar -czf backups/backup_previous.tar.gz -C public_html .

# Wipe old static assets
rm -rf public_html/*

# Extract new release archive into public_html
tar -xzf deploy.tar.gz -C public_html/

# Clean up archive
rm deploy.tar.gz

# Apply 755 directory permissions
chmod -R 755 public_html/
``g

## 4. Post-Deployment Smoke Tests & Verification

After any deployment, execute the following **4-Step Smoke Test**:

| # | Test Case | Action | Expected Result |
|---|---|---|---|
| 1 | **Home Page Access** | Open `https://tap.admin.trimify.com.au` | Login screen / Admin dashboard loads cleanly. |
| 2 | **SPA Refresh Guard** | Navigate to `/user-management` and press `F5` refresh | Page reloads without returning a 404 Not Found error. |
| 3 | **API Integration Check** | Open Browser DevTools (F12) -> Network tab, log in | Requests hit `adminbackend.trimify.com.au` returning HTTP `200 OK`. |
| 4 | **TinyMCE Editor Test** | Navigate to Blog Section or FAQ Management editor | Rich text toolbar, skins, and editor load correctly. |

If a deployed build contains critical bugs:

```bash

ssh username@SERVER_IP

# Navigate to application host folder
cd /home/tap.admin.trimify.com.au/

# Wipe failing build from public_html
rm -rf public_html/*

# Extract the previous backup archive
tar -xzf backups/backup_previous.tar.gz -C public_html/

# Restore permissions

``g
