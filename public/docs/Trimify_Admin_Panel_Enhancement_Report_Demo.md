**1. Overview**

The Trimify Admin Panel is a single place to manage the main parts of the platform. It includes users, health programs, diet plans, workouts, food data, subscriptions, payments, blogs, FAQs, website content, notifications, and admin accounts.

The panel is built to make daily work simpler. An admin can check important numbers, update content, manage records, and take follow-up actions from the relevant section.

**Main sections included**

| No. | Section | Main use |
| ---: | --- | --- |
| 1 | Login and Password Recovery | Secure access to the panel |
| 2 | Dashboard | Quick view of revenue, users, activity, alerts, and trends |
| 3 | Sub Admin Management | Add and manage sub-admin accounts |
| 4 | User Management | View users, profiles, activities, plans, and payments |
| 5 | Program Management | Create and maintain wellness programs and diet plans |
| 6 | Fitzone Management | Create and organise workout content |
| 7 | Data Management | Maintain nutrition data and AI food uploads |
| 8 | Blog Management | Maintain blog categories and blog posts |
| 9 | Subscription | View plans, subscribers, revenue, and transactions |
| 10 | Notification Management | Create and track notification campaigns |
| 11 | Content Management | Maintain FAQs and website pages |
| 12 | Admin Account | Update admin profile and security details |

**2. Login and Password Recovery**

This is the entry point of the admin panel.

| Available features | How it is used |
| --- | --- |
| Admin login with email and password | Lets authorised admin users enter the panel |
| Forgot-password flow | Starts password recovery when a password is forgotten |

| New-password setup | Lets the admin set a new password after verification |

**3. Dashboard**

The Dashboard is the first screen after login. It gives a quick picture of platform activity without opening every section one by one.

**Date filters**

Today, Yesterday, Last 7 Days, Last 30 Days, Last 90 Days, This Month, Last Month, and Custom Date Range are available for dashboard reporting.

**Dashboard summary cards**

| Card | What it shows |
| --- | --- |
| Revenue | Total successful payment amount for the selected period |
| Total Programs | Programs created during the selected period |
| Total Blogs | Blogs created during the selected period |
| Fitzone Sessions | Fitzone sessions created during the selected period |
| Missed Step Goals | Users who did not log steps in the selected period |
| Missed Diet Logs | Users who did not log food/diet in the selected period |
| Missed Water Logs | Users who did not log water in the selected period |
| Expiring Soon | Active subscriptions that will expire soon |

The main cards can show whether a value has increased or decreased compared with the previous similar period.

**Alerts and follow-up items**

| Alert | What it means |
| --- | --- |
| Ghosting Users | Users with no recent health activity |
| Content Stagnation | Programs or content that have not been updated recently |
| Zero Enrollment | Active programs that have not been assigned to any user |
| Quick action links | Opens the related section for follow-up |

**Charts and lists**

| Area | What it shows |
| --- | --- |
| User goal chart | Goals selected by newly registered users |
| Gender chart | Gender split of newly registered users |
| Food preference chart | Vegetarian, non-vegetarian, and unspecified preference split |
| Conversion funnel | Signups, paid users, unpaid users, conversion rate, and drop-off rate |
| Daily Active Users | Trend of users who logged health activity |
| Fitzone assignment trend | Users assigned to Fitzone content |
| Program enrolment chart | Programs that have received assignments/enrolments |
| Recent joined users | Latest user registrations |
| Unpaid-user list | Users available for payment follow-up |

The dashboard also includes loading states, empty states, and a last-updated indicator.

**Use:** Quickly check revenue, user activity, content activity, subscription follow-ups, and areas that need attention.

**Screenshots to include:** Full Dashboard, Alerts section, Charts section, and Follow-up table.
